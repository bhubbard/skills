# Cloudflare Plugin

Cloudflare Workers, Durable Objects, D1, KV, Queues, Workflows, Turnstile, and Kumo UI.

## Installation

### Antigravity 2.0 / CLI
```bash
agy plugin install ./plugins/cloudflare
# Or via GitHub subpath:
# agy plugin install github.com/user/repo/plugins/cloudflare
```

### Claude Code
```bash
claude plugin install ./plugins/cloudflare
```

### Cursor
Add to `.cursor/skills/` or reference skills in `.cursor/rules/`.
