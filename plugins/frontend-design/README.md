# Frontend-Design Plugin

High-end visual aesthetics, modern design systems, typography scales, and component styling.

## Installation

### Antigravity 2.0 / CLI
```bash
agy plugin install ./plugins/frontend-design
# Or via GitHub subpath:
# agy plugin install github.com/user/repo/plugins/frontend-design
```

### Claude Code
```bash
claude plugin install ./plugins/frontend-design
```

### Cursor
Add to `.cursor/skills/` or reference skills in `.cursor/rules/`.
