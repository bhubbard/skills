# Wordpress Plugin

WordPress core, block themes, WP-CLI, Gutenberg, Gravity Forms, and Yoast SEO.

## Installation

### Antigravity 2.0 / CLI
```bash
agy plugin install ./plugins/wordpress
# Or via GitHub subpath:
# agy plugin install github.com/user/repo/plugins/wordpress
```

### Claude Code
```bash
claude plugin install ./plugins/wordpress
```

### Cursor
Add to `.cursor/skills/` or reference skills in `.cursor/rules/`.
