# Seo Plugin

Technical SEO, Core Web Vitals, Google Search Console, Schema markup, and Unlighthouse.

## Installation

### Antigravity 2.0 / CLI
```bash
agy plugin install ./plugins/seo
# Or via GitHub subpath:
# agy plugin install github.com/user/repo/plugins/seo
```

### Claude Code
```bash
claude plugin install ./plugins/seo
```

### Cursor
Add to `.cursor/skills/` or reference skills in `.cursor/rules/`.
